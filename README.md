# 🐾 Pati Dostu

Merhaba! **Pati Dostu**, kedi ve köpek sahiplerinin bir araya gelip deneyimlerini paylaşabileceği, sorular sorabileceği ve sosyalleşebileceği sıcak bir topluluk platformudur. Bu projeyi geliştirirken hayvan severlerin ihtiyaç duyabileceği güvenilir bilgiye ulaşmalarını ve birbirleriyle etkileşimde bulunmalarını hedefledim.

## 🚀 Proje Hakkında

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş bir sosyal platformdur. Kullanıcılar üye olabilir, forumda konu açabilir, yorum yapabilir ve profillerini düzenleyebilirler.

### Özellikler

- **Forum Sistemi**: Kategori bazlı konu açma, yorum yapma ve beğeni sistemi.
- **Kullanıcı Profilleri**: Kişiselleştirilebilir profiller ve aktivite geçmişi.
- **Eğitim İçerikleri**: Kedi ve köpek bakımı hakkında bilgilendirici makaleler.
- **Responsive Tasarım**: Mobil ve masaüstü uyumlu modern arayüz.

## 🛠️ Kullanılan Teknolojiler

Projeyi geliştirirken kullandığım temel teknolojiler:

- **Frontend**: React, Vite
- **Stil**: Tailwind CSS
- **Backend / Veritabanı**: Firebase (Authentication, Firestore)
- **İkonlar**: Material Symbols

## 💻 Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak isterseniz:

1.  Repoyu klonlayın:
    ```bash
    git clone https://github.com/efe-inan/pati-dostu.git
    ```
2.  Proje dizinine gidin:
    ```bash
    cd pati-dostu
    ```
3.  Bağımlılıkları yükleyin:
    ```bash
    npm install
    ```
4.  Projeyi başlatın:
    ```bash
    npm run dev
    ```
